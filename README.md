# Movie Watchlist

A personal application for organizing movies.

## Features

- Movie titles and years
- Watched status
- Viewing progress

## How to Use

Add a movie and update its viewing status.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Add a movie with a valid release year.
- [ ] Change its watched status and review the summary.
- [ ] Remove the movie and confirm the total updates.
